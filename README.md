# 품:ON - 유기동물 보호소 수용현황 분석 & 연결 플랫폼

> 공공데이터 기반 보호소 과밀 예측 및 분산 보호 연결 서비스

## 프로젝트 소개

본 프로젝트는 공공 유기동물 데이터와 보호소 현황 데이터를 분석하여 보호소의 수용 압박 상태를 시각화하고, 향후 위탁 보호 연결 및 분산 보호를 지원하는 중개 플랫폼입니다.

단순 유기동물 조회 서비스가 아닌, **데이터 분석 기반 문제 해결형 서비스**라는 점이 핵심입니다.

## 기획 배경

- 매년 **10만 마리 이상**의 유기동물 발생
- 보호소별 수용 능력 편차 심각
- 과밀 보호소 발생 → 안락사 증가 → 구조 악순환
- 기존 서비스는 "공고/입양 정보 제공" 중심, **보호소 운영 관점 데이터 분석 서비스 부족**

**→ 보호소 수용 압박도 시각화 + 분산 보호 연결 기반 서비스 기획**

## 핵심 기능

### 1. 보호소 수용 압박도 분석
- 구조동물 수 / 보호소 최대 수용 가능 수 기반 현재 수용 비율 계산
- 압박도 지수 시각화 (위험 70% 이상 / 경고 40% 이상 / 여유 39% 이하)

### 2. 지역별 유기동물 분포 대시보드
- Low Poly Map 기반 지역별 수용 현황 시각화
- Chart.js 기반 통계 차트
- 위기 보호소 TOP 5 실시간 표시

### 3. 날짜별 데이터 누적 저장
- Firebase RTDB에 일자별 데이터 저장
- API 호출 최소화를 위한 데이터 캐싱 구조

### 4. 사용자 인증 시스템
- 보호소 / 임시보호자 회원 구분
- 역할 기반 접근 제어

### 5. 향후 확장 기능 (기획 단계)
- 과밀 예측 시스템 (일일 증가량 기반)
- 위탁 보호 가능자 매칭 시스템
- 지자체 협업 운영 도구 확장

## 기술 스택

| 구분 | 기술 |
|------|------|
| Frontend | HTML, CSS, JavaScript (Vanilla) |
| Chart | Chart.js |
| Map | Canvas 기반 Low Poly Map, Kakao Map |
| Backend (BaaS) | Firebase Realtime Database, Firebase Auth |
| Proxy Server | Express.js, CORS |
| API | 공공데이터포털 유기동물 조회 API, 경기도 보호시설 API |
| Version Control | Git, GitHub |

│   ├── animal.js           # 입양동물 페이지 로직
│   ├── foster-*.js         # 임시보호자 관련 모듈
│   ├── firebase-auth.js    # Firebase 인증 및 헤더 UI

│   └── ...

## 데이터 처리 구조

```
공공 유기동물 조회 API
        ↓
일자별 데이터 수집
        ↓
Firebase RTDB 저장
(rescuedAnimals/yyyy-mm/dd)
        ↓
보호소 전화번호 기준 매칭
        ↓
최대수용수 대비 현재 수용 비율 계산
        ↓
대시보드 시각화
```

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 프록시 서버 실행 (API CORS 우회)
node proxy.cjs

# 브라우저에서 http://127.0.0.1:8787 접속
```
